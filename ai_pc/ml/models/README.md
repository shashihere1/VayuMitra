# models/

Model artifacts live here. Generated by the ML pipeline (see `../README.md`).

| File | Produced by | Commit? | Notes |
|---|---|---|---|
| `scaler.json` | `train_risk.py` | yes | per-feature mean/std applied at inference |
| `risk_fp32.onnx` | `train_risk.py` | yes | FP32 CPU model + export source for quantize/tflite |
| `risk_int8.onnx` | `quantize.py` (**x64**) | yes | static QDQ INT8 for the NPU (QNN EP) |
| `risk_qnn_ctx.bin` | first NPU run | no (regenerated) | QNN HTP context cache |
| `risk.tflite` | `to_tflite.py` | copied to mobile assets | phone on-device model |

If none of these exist, the orchestrator runs the pure-Python **heuristic** —
the system is fully functional without any committed model (P0).
